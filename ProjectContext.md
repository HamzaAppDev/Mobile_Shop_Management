# 📱 MobileShop App – Project Context

## 1. Project Overview

MobileShop is a React Native (Expo) application designed for small mobile shop businesses to manage:

- Sales transactions
- Expense tracking
- Customer payments (Cash / Online / Udhar)
- Daily/monthly financial summaries
- Filtering and reporting via bottom sheets

The app is optimized for:

- Speed
- Simplicity
- Shopkeeper usability
- Clean, professional UI
- Modular and scalable architecture

This is NOT an enterprise ERP.
This is a focused, high-clarity retail business tracker.

---

## 2. Core Features

### Sales

- Add sale
- Track payment method
- Filter by:
  - Date preset
  - Custom date range
  - Item
  - Payment type
- Summary header (total sales)

### Expenses

- Add expense
- Filter by:
  - Date
  - Category
- Expense summary header
